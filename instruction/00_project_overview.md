# AI句会ワークショップ - プロジェクト概要

## プロジェクトビジョン

中高年層を主な対象とした、AI技術を活用した俳句ワークショップアプリケーション。伝統的な日本の句会文化を尊重しながら、現代のAI技術を教育的な補助ツールとして統合することで、俳句創作の学習と楽しみを促進する。

## 背景と目的

### 社会的背景
- 公民館などの地域コミュニティにおける俳句活動の活性化
- 中高年層のデジタルリテラシー向上とAI技術への親しみ創出
- 伝統文化の継承と現代技術の融合

### プロジェクト目的
1. **アクセシビリティ**: AI技術に不慣れな中高年層でも使いやすいインターフェース
2. **文化的真正性**: 伝統的な俳句・句会の本質を損なわない設計
3. **教育的価値**: AI支援による学習促進と創作意欲の喚起
4. **コミュニティ形成**: 参加者間の交流と共創の場の提供

## ターゲットユーザー

### 主要ユーザー
- **ワークショップ参加者**: 中高年層を中心とした俳句愛好者・初心者
- **ファシリテーター**: 公民館職員、俳句講師、ワークショップ進行役

### ユーザー特性
- デジタル機器への慣れが限定的
- 俳句に対する関心はあるが、創作経験は様々
- 対面でのコミュニケーションを重視
- 文化的伝統への敬意

## 主要モード

### 1. ペアモード
2人での親密な俳句創作セッション

**特徴**:
- リアルタイム協働作句
- 個別の俳画（haiga）生成
- 相互投票と鑑賞
- 軽量でシンプルな設計

**想定利用シーン**:
- 友人同士の俳句創作
- 師弟での学習セッション
- 家族でのレクリエーション

### 2. グループモード
公民館などでの大規模ワークショップ向け

**特徴**:
- 複数参加者の同時作句
- ファシリテーター主導の進行管理
- 集合的な統計分析とランキング
- 包括的なワークショップレポート

**想定利用シーン**:
- 公民館での定期俳句教室
- 文化イベントでのワークショップ
- 地域コミュニティの句会

## 技術スタック

### フロントエンド
- **フレームワーク**: React 18 + TypeScript
- **UI**: Tailwind CSS
- **アイコン**: Lucide React
- **状態管理**: React Hooks (useState, useReducer)

### AI統合
- **API**: Anthropic Claude API
- **活用機能**:
  - 俳句生成・提案
  - 推敲支援
  - 講評・フィードバック
  - 俳画（画像）生成

### アーキテクチャ特性
- シングルページアプリケーション (SPA)
- クライアントサイドレンダリング
- RESTful API通信

## 文化的配慮と設計原則

### 伝統の尊重
1. **季語の重視**: 季語辞書の統合と季節感の教育
2. **形式の維持**: 五七五の音数律厳守
3. **句会文化**: 伝統的な句会の流れ（作句→披講→選句→講評）を踏襲

### AI活用の哲学
- **補助ツールとしての位置づけ**: AIは創作の主体ではなく学習支援
- **人間の最終判断**: AI提案はあくまで参考、最終決定は創作者
- **教育的活用**: 語彙拡張、表現学習、推敲の視点提供

### アクセシビリティ原則
- 大きく読みやすいフォント
- 明瞭なコントラストと配色
- シンプルで直感的なナビゲーション
- 過度な機能の詰め込みを避ける

## プロジェクトの現状

### 開発段階
- **Phase 1 (完了)**: ペアモードプロトタイプ開発
- **Phase 2 (完了)**: グループモードプロトタイプ開発
- **Phase 3 (現在)**: 機能統合と検証準備

### 実装済み主要機能
- 基本的な作句インターフェース
- AI俳句生成・推敲支援
- 季語辞書統合
- 投票システム
- 俳画生成（ペアモード）
- 統計分析とランキング（グループモード）
- ワークショップレポート出力
- バッジ・成長トラッキング
- 連歌（renga）機能

## プロジェクトの独自性

### 差別化要因
1. **文化特化**: 俳句という特定文化領域への深い理解
2. **世代配慮**: 中高年層に特化したUX設計
3. **教育重視**: AI補助による学習促進メカニズム
4. **コミュニティ志向**: 個人創作と集団活動の両立

### 社会的意義
- 伝統文化のデジタル保存と継承
- 世代間デジタルデバイドの緩和
- 地域コミュニティの活性化
- AI技術の文化的・教育的応用モデルの提示
