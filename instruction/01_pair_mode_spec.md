# ペアモード詳細仕様

## モード概要

ペアモードは、2人の参加者が親密な環境で俳句創作を楽しむためのモードです。リアルタイムでの協働、AI支援による学習、そして相互の作品鑑賞を通じて、俳句創作の喜びを共有します。

## 設計思想

### コアコンセプト
- **親密性**: 2人という少人数だからこその深い対話
- **協働性**: 共に学び、共に創る体験
- **軽量性**: シンプルで直感的な操作感
- **個性尊重**: 各自の創作スタイルを大切に

### 想定利用シーン
1. 友人同士での俳句創作タイム
2. 師弟関係での学習セッション
3. カップル・夫婦でのレクリエーション
4. 親子での文化体験

## 主要機能

### 1. セッション管理

#### セッション開始
```
[参加者A] ←→ [アプリケーション] ←→ [参加者B]
```

**フロー**:
1. 一方がセッションを作成
2. もう一方が参加コード（または直接接続）で参加
3. 両者の接続確認
4. セッション開始

**技術実装**:
- 軽量な状態管理（useState）
- 擬似的な同期（実際はローカル状態）

### 2. 季語選択

#### 季語辞書統合
- 春夏秋冬＋新年の季語データベース
- カテゴリ別分類（天文・地理・生活・行事・動物・植物）
- 各季語の説明文と例句

**UI要素**:
```
┌─────────────────────────────────┐
│ 季節選択: [春] [夏] [秋] [冬] [新年]│
├─────────────────────────────────┤
│ カテゴリ: [天文] [地理] [生活]...  │
├─────────────────────────────────┤
│ 季語一覧:                        │
│ ・桜 - 春の代表的な花...         │
│ ・朧月 - 春の夜の月...           │
│ ...                              │
└─────────────────────────────────┘
```

**インタラクション**:
- 季語クリックで詳細表示
- 選択した季語がハイライト
- 「この季語で作る」ボタン

### 3. 作句インターフェース

#### 入力欄
```
┌─────────────────────────────────┐
│ 五音: [_______________]         │
│ 七音: [_______________]         │
│ 五音: [_______________]         │
├─────────────────────────────────┤
│ 選択中の季語: 桜                │
│ 現在の音数: 5-7-5 ✓             │

```

**機能**:
- リアルタイム音数カウント
- 五七五形式の視覚的ガイド
- 季語の自動ハイライト

### 4. 俳画（Haiga）生成

#### 概要
俳句に合わせた水墨画風のイラストをAI生成

**生成フロー**:
```
[俳句完成] → [俳画生成リクエスト] → [Claude API]
  ↓
[画像生成プロンプト作成] → [画像生成]
  ↓
[俳句と俳画の合成表示]
```

**プロンプト設計**:
```
"Create a traditional Japanese haiga (俳画) style illustration for this haiku:
[俳句内容]

Style: Minimalist sumi-e (ink wash painting), simple brush strokes, 
capturing the essence of the season and mood. 
Focus on [季語に関連する要素]."
```

**表示形式**:
```
┌─────────────────────────────────┐
│        [生成された水墨画]        │
│                                  │
│      古池や                      │

```

## ユーザーフロー

### 標準的なセッションの流れ

```
1. セッション開始
   ↓
2. 季語選択（共同または個別）
   ↓
3. 作句タイム
   ├─ AI提案を参考にする
   ├─ 自力で作る
   └─ 推敲支援を受ける
   ↓
4. 俳画生成（オプション）
   ↓
5. 相互投票
   ↓
6. 結果発表とAI講評
   ↓
7. セッション記録保存
   ↓
8. 次のセッション or 終了
```

### 所要時間
- 季語選択: 3-5分
- 作句: 10-15分
- 投票・鑑賞: 5分
- **合計**: 約20-25分/セッション

## UI/UXデザイン

### デザイン原則

1. **大きく読みやすい**: フォントサイズ18px以上
2. **余白の確保**: 情報過多を避ける
3. **明瞭なコントラスト**: 視認性の確保
4. **直感的な操作**: 説明不要のUI

### カラーパレット

```
背景: #F8F9FA (明るいグレー)
メインカラー: #2C5F2D (深緑 - 和の印象)
アクセント: #DC143C (紅 - 季節感)
テキスト: #1A1A1A (濃いグレー)
ボーダー: #E0E0E0 (淡いグレー)
```

### レスポンシブ対応

- デスクトップ: 2カラムレイアウト（参加者A | 参加者B）
- タブレット: 1カラム（縦スクロール）
- スマートフォン: 最小限の機能（基本作句のみ）

### AI API呼び出し例

```typescript
// 俳句提案
async function generateHaikuSuggestions(kigo: string): Promise<string[]> {
  const response = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: 'claude-sonnet-4-5-20250929',
      max_tokens: 1000,
      messages: [{
        role: 'user',
        content: `季語「${kigo}」を使った俳句を3句提案してください。`
      }]
    })
  });
  
  const data = await response.json();
  return parseHaikusFromResponse(data.content);
}
```

## アクセシビリティ配慮

### 高齢者向け最適化
- **フォント**: ゴシック体、18px以上
- **行間**: 1.8em
- **ボタン**: 最小48x48px（タップしやすいサイズ）
- **色**: コントラスト比4.5:1以上

### キーボード操作
- Tab順序の最適化
- Enterキーでの送信
- Escキーでのキャンセル

### スクリーンリーダー対応
- 適切なARIAラベル
- セマンティックHTML
- フォーカス管理

## 制約と今後の課題

### 現在の制約
1. **同期機能なし**: 真のリアルタイム協働は未実装
2. **オフライン非対応**: インターネット接続必須
3. **モバイル最適化**: 限定的な対応

### 今後の改善点
1. WebSocketによるリアルタイム同期
2. Progressive Web App (PWA) 化
3. 音声入力機能の追加
