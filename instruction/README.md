## 💡 notebookLMでの活用例

### 1. 構想の再整理
**質問例**:
- 「このプロジェクトの核心的な価値は何ですか？」
- 「ペアモードとグループモードの最大の違いは？」
- 「文化的に最も配慮すべき点は？」

### 2. ギャップ分析
**質問例**:
- 「実装済み機能と未実装機能のリストを作成してください」
- 「Phase 2で最優先すべきタスクは？」
- 「技術的な課題はどこにありますか？」

### 3. プレゼン資料作成
**質問例**:
- 「投資家向けピッチデックの構成案を作成してください」
- 「公民館向けの説明スライドの内容を提案してください」
- 「3分間のエレベーターピッチを作成してください」

### 4. 研究テーマ抽出
**質問例**:
- 「このプロジェクトから派生する研究テーマを5つ挙げてください」
- 「学会発表に適したデータはどこにありますか？」
- 「文化人類学的な考察ポイントは？」

### 5. リスク評価
**質問例**:
- 「このプロジェクトの最大のリスクは何ですか？」
- 「文化的批判を受ける可能性のあるポイントは？」
