# 俳句アプリ　操作ガイド

お父様ご自身が、自尊心を持って楽しく操作できるよう、手順をまとめました。  
印刷して手元に置き、お品書きのようにご参照ください。

---

## ① お題を選ぶ

1. 好きな写真を画面に表示します。
2. 写真から出てきた「季節の言葉」を、指でひとつ選びます。
3. 季語辞典から選ぶ場合は、検索欄に文字を入力するか、春・夏・秋・冬のタブを押して、気になる言葉を選びます。
4. 選んだ季語のすぐ上に「この季語をお題にする」と出たら、そのボタンを押します。

---

## ② 指で書く

1. 「指で書く（デジタル半紙）」のボタンを押します。
2. 白い画面に、横書きの線が三本引かれています。
3. その線の間に、指で「五・七・五」の俳句を横に書いてください。
4. 間違えた場合は、「書き直す（消去）」を押して、最初から書き直すことができます。
5. 書き終えたら「これで決める（完了）」を押します。
6. 画面が「書いた字を読み取っています…」と表示されます。しばらくお待ちください。

---

## ③ 言葉を整える

1. 読み取られた俳句が画面に表示されます。
2. 「AIに相談する」のボタンを押すと、より良い表現を提案してくれます。
3. 提案された中から、気に入ったものをタップすると、その言葉に差し替わります。
4. そのままの句で良ければ、そのままで構いません。
5. 「このヒントをもとに直す」または「今の提案を参考にして次へ進む」を押して、次のステップへ進みます。

---

## ④ 作品を確認する

1. 画面に、送信前の俳句が表示されます。
2. 修正したい場合は、その欄に直接指やキーボードで書き直すことができます。
3. 自分の書いた字が、写真の隅に「はんこ」のように載ることも確認できます。
4. 「この句をみんなに送る」を押して、作品を披露します。

---

## ⑤ 紙に印刷する

1. 「句の履歴」を開きます。
2. 印刷したい俳句を選び、「印刷プレビュー」を押します。
3. 写真カードのような画面が出たら、自分の字をはんことして載せるか選べます。
4. 「印刷」ボタンを押すと、目の前のプリンターから写真カードが出てきます。
