# 俳句アプリ 操作ガイド（ウィザード形式）

アプリの画面の流れに沿った、5ページ構成の操作マニュアルです。各ページは Figma のフレームにそのままコピーしてご利用いただけます。

# 【第一歩：お題を選ぶ】

**Step 1 / 5**

## どこを見るか

- 画面上部：散歩の写真や、季節の言葉（季語）のリスト
- 写真がない場合は「季語辞典から選ぶ」のリンク
- 季語を選ぶと、そのすぐ上に「この季語をお題にする」ボタンが表示されます

## 何をするか

1. 写真から提案された季語、または季語辞典の一覧を見る
2. 好きな言葉を指でタップして選ぶ
3. 表示された「この季語をお題にする」ボタンを押す

## 応援の一言

> この写真のどこが、お心に残りましたか？ その思いが、今日の一句になります。

# 【第二歩：指で書く】

**Step 2 / 5**

## どこを見るか

- 画面中央：三本の横線が引かれた白い画面（デジタル半紙）
- 画面上部：今日のお題（季語）が表示されています
- 下部：「書き直す（消去）」と「これで決める（完了）」のボタン

## 何をするか

1. 「指で書く（デジタル半紙）」ボタンを押して、白い画面を開く
2. 線と線の間に、指で一文字ずつ「五・七・五」を横に書く
3. 書き終えたら「これで決める（完了）」を押す
4. アプリが書いた字を読み取ります（少しお待ちください）

## 応援の一言

> ゆっくり書くと、きれいに読み取れます。指を動かすのも、立派な体操ですよ。

# 【第三歩：言葉を整える】

**Step 3 / 5**

## どこを見るか

- 画面上部：「いまの句（編集できます）」の枠に、読み取られた俳句が表示されています
- その下：「AIからの提案（参考）」を開くと、言い換えの案が表示されます
- 「AIに相談する」ボタンで、新しい提案を得られます

## 何をするか

1. 読み取られた句を確認し、必要なら枠内で直す
2. 「AIに相談する」を押すと、AIがより良い表現を提案してくれます
3. 気に入った案があれば、その案を指でタップして選ぶ
4. 問題なければ「AIに相談する前へ」または「提出する前へ」を押して次へ進む

## 応援の一言

> AIさんが、少し言い方を整えてくれました。お好みの方を、どうぞお選びください。

# 【第四歩：作品を確認する】

**Step 4 / 5**

## どこを見るか

- 画面中央：「この句でよろしければ、みんなに送信します」のメッセージ
- その下：今日詠んだ俳句が、訂正できる枠に表示されています
- 印刷時には、自分の書いた字が「はんこ」のように写真の隅に載ります

## 何をするか

1. 表示された俳句を、最後にもう一度確認する
2. 直したいところがあれば、枠内をタップして訂正する
3. 自分の名前（はんこ）の位置を心に留めておく（印刷プレビューで確認できます）
4. 良ければ「この句をみんなに送る」を押す

## 応援の一言

> お父様の字が、立派な「はんこ」になります。世界に一つだけの作品です。

# 【第五歩：紙に印刷する】

**Step 5 / 5**

## どこを見るか

- 披講（鑑賞）画面で、二人の句が並んで表示されます
- 「句の履歴」に移動すると、過去の句の一覧が表示されます
- 印刷したい句を選び「印刷プレビュー」を開くと、L判サイズの写真カードが表示されます

## 何をするか

1. Step 5 の披講画面で、二人の句を並べて鑑賞する
2. ホームに戻り、「句の履歴」を開く
3. 印刷したい句のカードを選び、「印刷」または「印刷プレビュー」を押す
4. 自分の名前（はんこ）を載せる場合は、チェックを入れる
5. ブラウザの「印刷」ボタンを押し、プリンターからカードが出てくるのを待つ

## 応援の一言

> ノートに貼って、日付やその日の出来事を書き添えれば、思い出の一冊になります。
